# Weather App

I built this weather app because I wanted something simple that shows everything, not just the temperature. Humidity, wind, UV, air quality, the whole picture. No frameworks, no build tools, just plain HTML, CSS, and JavaScript.

Type in any city and it pulls live weather data. That's it.

# What it shows

Temperature in Celsius and Fahrenheit, what it actually feels like, the weather condition, humidity, cloud cover, visibility, wind speed and direction, pressure, precipitation, UV index, air quality readings, and the city's coordinates and local time.

# Running it

Clone the repo. Get a free API key from WeatherAPI. Paste the key into app.js where it says YOUR_API_KEY. Open index.html in your browser. Done.

# Files

Just four files — index.html, style.css, app.js, and a logo image. That's the whole project.

# Tweaking it

Want a different default city? Change the value in app.js. Want the background watermark stronger or fainter? Adjust the opacity in style.css. Want a different color scheme? All the colors sit at the top of style.css in one place.

# Things I know are imperfect

The API key is visible in the code. Fine for a hobby project, but you'd want to hide it if this ever got real traffic. It only shows current weather, no forecast. Maybe later.
